# Day 1: Training with VS Code and Claude Code

## What I learned

- **VS Code** is a free code editor made by Microsoft.
- We can build customized tools for any process the company currently does manually. Manual processes create unexpected errors, so VS Code can help improve the process by developing a tool.
- VS Code can work with large data, is very handy for getting things done, and makes it easy to flag mistakes and errors in the process.
- VS Code can suggest better options and better solutions for tools and processes.
- **Git** is a tool for tracking changes made in code.
- VS Code has extensions for Java, Python, Claude Code, etc., so no matter which language you build the tool in, it will help.
- VS Code can read the folders and files on the computer, making it easy to get the particular data needed.

## Git commands I learned

| Command | What it does |
|---|---|
| `git init -b main` | Turns a folder into a Git repository with a `main` branch |
| `git config --global user.name "..."` | Sets the name shown on my commits |
| `git add .` | Stages all changed files for the next commit |
| `git commit -m "message"` | Saves a snapshot with a message describing the change |
| `git commit -am "message"` | Stages changes to tracked files and commits in one step |
| `git remote add origin <URL>` | Connects the local folder to a GitHub repository |
| `git push -u origin main` | Uploads commits to GitHub the first time (later just `git push`) |

My routine after changing files: `git add .` → `git commit -m "..."` → `git push`
